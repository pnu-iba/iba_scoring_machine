과제

영국 중고차 거래 데이터로 차량 가격을 예측하는 회귀 모델을 만듭니다.
train.csv로 학습하고, test.csv의 각 차량에 대한 예측 가격을 제출합니다.

데이터 및 코드

파일내용
train.csv학습 데이터
test.csv예측 대상
sample_submission.csv제출 형식 예시
test.csv와 행 순서가 같으며 price는 무작위 값입니다.
brand_model.csvbrand·model의 전체 클래스 목록
인코더를 fit할 때 쓰면 train에 없는 model도 처리할 수 있습니다.
IBA_reg_comp_BASELINE.ipynb제출 파일을 생성할 수 있는 baseline 코드 예시
test.csv의 id는 0부터 39,084까지의 행 번호입니다. 제출 파일도 test.csv와 같은 행 순서를 유지하세요.

채점 방식

주 지표
RMSE: 리더보드 순위 기준. 낮을수록 좋습니다.
보조 지표
R²: 참고용. 1에 가까울수록 좋습니다.
중간 채점
Public: test.csv에서 무작위로 고른 30%(중복 없이)로 매긴 점수.
제출 결과와 대회 중 리더보드에 이 점수가 나옵니다. 어느 행이 public인지는 공개하지 않습니다.
최종 채점
Private: 마감 뒤 test.csv 전체로 다시 채점해 최종 순위를 정합니다.
팀마다 public 점수가 가장 좋았던 제출 1건이 사용됩니다.
음수 예측
0으로 바꿔 채점하고 몇 건이었는지 알려줍니다.
기준선
sample_submission.csv를 그대로 채점했을 때 RMSE는 약 13,190입니다. (아무것도 안 한 점수)

Public과 Private를 나누는 이유

테스트셋은 모델이 한 번도 보지 못한 데이터여야 일반화 성능을 제대로 잴 수 있습니다. 그런데 제출할 때마다 점수가 보이면 그 점수가 오르는 쪽으로 모델을 고치게 되고, 테스트셋이 사실상 validation set 역할을 하게 됩니다. 그래서 대회 중에는 테스트셋의 일부로만 점수를 보여주고, 최종 순위는 대회 중 점수에 쓰이지 않은 70%가 들어간 전체 데이터로 매깁니다.

제출 규칙

  • sample_submission.csv와 동일한 형식으로 제출합니다: 헤더 id,price, 데이터 39,085행, test.csv와 같은 순서.
  • 제출 횟수는 팀당 하루 3회로 제한되며 자정에 초기화됩니다.
  • 제출하려면 로그인해야 합니다. 가입할 때 팀 번호는 한자리 숫자만 입력합니다.
  • 최종 마감날 자정이 지나면 제출이 막히고 최종 순위가 공개됩니다.

주의사항

  • id 열은 test.csv의 순서와 값이 모두 같아야 합니다. 정렬하거나 섞지 마세요. 채점은 행 순서로 짝지어 이루어집니다.
  • price는 빈 값 없이 모두 숫자여야 합니다. 음수는 0으로 바꿔 채점합니다.
  • 형식 오류로 거부된 제출은 횟수에 들어가지 않습니다.
